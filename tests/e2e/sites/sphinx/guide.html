Guide¶

Open a device with toyapi.driver.Accelerator, build a Graph, apply toyapi.graph.ops.relu(), and finish with toyapi.graph.Graph.output().

from toyapi.graph import (
    Graph,
    ops,
)
from toyapi import driver
device = driver.Accelerator()
print(device.id)
with Graph("g") as graph:
    graph.output(ops.relu(x))

A doctest block:

>>> from toyapi.graph import Graph
>>> g = Graph("g")

A default-language literal block:

from toyapi.graph import Graph
graph = Graph("plain")
