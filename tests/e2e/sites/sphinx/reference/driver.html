driver¶

Device discovery and management.

This module exposes the devices that graphs run on.

class toyapi.driver.Accelerator(id: int = 0)¶

Bases: Device

A GPU or other accelerator device.

Use accelerator_count() to find how many accelerators exist.

class toyapi.driver.CPU(id: int = 0)¶

Bases: Device

The host CPU device.

There is one CPU device per process, and its identifier is zero.

class toyapi.driver.Device(id: int = 0)¶

Bases: object

A compute device that can run graphs.

Devices are created through subclasses such as CPU and Accelerator. Each device has an integer identifier.

property id: int¶

The integer identifier of this device.

Identifiers are unique per device type and start at zero.

synchronize() → None¶

Block until all queued work on the device finishes.

Call this before reading results produced on the device.

toyapi.driver.accelerator_count() → int¶

Return the number of available accelerators.

Returns zero when the host has no accelerators.

Returns:

The accelerator count.
